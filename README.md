# ChainCore – Mini Blockchain Implementation

ChainCore is an educational blockchain simulator developed using C++. It demonstrates blockchain fundamentals through block creation, SHA-256 hashing, transaction storage, hash linking and integrity verification.

### Features
- Block creation and transaction storage
- SHA-256 cryptographic hashing
- Previous block hash linking
- Blockchain integrity verification
- Tampering attack simulation
- Automatic tampering detection

### Technologies
- C++11
- Object-Oriented Programming
- SHA-256
- STL and Vectors
- Data Structures

### How to Run
1. Clone this repository.
2. Open `main.cpp` in Dev-C++.
3. Compile and run the program.
4. Follow the interactive menu.

### Learning Outcomes
- Understand blockchain architecture.
- Learn cryptographic hashing.
- Understand block-to-block connectivity.
- Explore data integrity and tampering detection.

### Disclaimer
This is an educational blockchain simulator, not a production cryptocurrency or distributed blockchain network.
